Global Navigation Satellite System (GNSS) IGS Multi-GNSS Experiment (MGEX)
Products from NASA CDDIS

This derived product set consists of Global Navigation Satellite System satellite orbit products (daily files, generated daily) from the real-time IGS analysis center submissions available from NASA Crustal Dynamics Data Information System (CDDIS).
