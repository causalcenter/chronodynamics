# Code Review Skill

When reviewing code, follow these steps:

## Review checklist

1. **Correctness**: Does the code do what it's supposed to?
2. **Error Handling**: Are error conditions correctly handled? No silent failures?
3. **Style**: Does it follow Rust conventions and project conventions defined in AGENTS.md?
4. **Security**: Does it follow source code security best practices?
5. **Performance**: Are there obvious inefficiencies?

## How to provide feedback

- Be specific about what needs to change
- Explain why, not just what
- Suggest alternatives when possible
