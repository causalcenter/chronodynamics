draft manuscripts and have not yet undergone peer review.

1. Hansen, M. (2026). *Recovery of the Geocentric Gravitational Constant from
   Galileo Satellite Clock Data via Chronometric Inversion*. Preprint, January
   2026. [PDF](papers/preprints/chrono_mass.pdf)

2. Hansen, M. (2026). *Forensic Reconstruction of the 2016–2017 Galileo Clock
   Crisis via Temporal Principal Component Analysis*. Preprint, January 2026.
   [PDF](papers/preprints/clock_crisis.pdf)

## Dataset

The full reference data set (25 GB) is available at Zenodo:

Hansen, M. (2026). Canonical dataset for chronometric analysis.
Zenodo. https://doi.org/10.5281/zenodo.20020236

Please download the dataset, unzip it, and drop it into the chrono_data_manager.

The resulting folder structue should be:

chrono_data_manager/data/
    gnss    
    ipta    
    omni    
    output  
    zenodo
